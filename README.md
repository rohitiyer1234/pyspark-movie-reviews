# IMDb Movie Review Analysis using PySpark

## Overview
A beginner-level big data analysis project using Apache PySpark to process and analyze the IMDb Movie Review Dataset containing 50,000 movie reviews.

## Dataset
[IMDb Dataset of 50K Movie Reviews – Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

The dataset contains two columns:
- `review`: Movie review text.
- `sentiment`: Positive or negative.

## Tasks Performed
- Loaded the CSV dataset into a PySpark DataFrame.
- Explored the schema and displayed sample records.
- Removed null and empty reviews.
- Counted total, positive, and negative reviews.
- Created a `review_length` column.
- Filtered reviews longer than 500 characters.
- Saved the cleaned and transformed dataset as CSV.

## Technologies Used
- Python
- Apache PySpark
- Google Colab
- Git and GitHub

## How to Run
1. Clone this repository.
2. Open the notebook in Google Colab.
3. Download the dataset from Kaggle and upload the CSV when prompted.
4. Execute the notebook cells sequentially.
