# IMDb Movie Review Analysis using PySpark

## Objective
Analyze the IMDb Movie Review Dataset using Apache
PySpark to perform data loading, exploration,
cleaning, analysis and transformation.

## Dataset
IMDb Dataset of 50K Movie Reviews.

Source:
[https://www.kaggle.com/datasets/lakshmi25npathi/
imdb-dataset-of-50k-movie-reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

## Technologies Used
- Python
- Apache PySpark
- Google Colab

## Tasks Performed

1. Loaded the IMDb dataset into a PySpark DataFrame.
2. Explored the dataset schema and displayed records.
3. Removed null and empty reviews.
4. Counted total, positive and negative reviews.
5. Created a review_length column.
6. Filtered reviews longer than 500 characters.
7. Saved the cleaned and transformed dataset as CSV.

## Execution
Open the notebook using Google Colab.
Upload the downloaded IMDb Dataset.csv file
and execute the cells sequentially.
